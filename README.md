# 🚀 BitFinder Survey

**BitFinder Survey** is a mobile-first, single-purpose web questionnaire app created for **Bitnox Technology (Abeokuta)**. 

Built by **Goodness Boluwatife** (Machine Learning student), this tool collects data from students in the Bitnox office to train the **BitFinder AI model** — designed to help students discover their optimal tech course and career path.

---

## 🌟 Key Features

- **Mobile-First Experience**: High-contrast dark tech theme with glassmorphic cards and touch targets.
- **12 Guided Questions**:
  1. Age Range
  2. Education Level
  3. Current Status
  4. Tech Experience
  5. Interest Areas (Max 3)
  6. Learning Style
  7. Main Goal
  8. Available Time Schedule
  9. Budget Range
  10. Preferred Career Path (Max 2)
  11. Bitnox Course Picked
  12. Personal Tech Vision (20–300 characters live validation)
- **Database & Cloud Storage**:
  - Exact column matching: `age_range`, `education_level`, `current_status`, `tech_experience`, `interest_areas`, `learning_style`, `main_goal`, `available_time`, `budget_range`, `career_path`, `course_picked`, `achievement_text`, `submitted_at`.
  - Dual storage: Integrated **Supabase Cloud Client** with **LocalStorage backup**.
- **Admin Dashboard**:
  - Password protected (Default password: `bitnox2026`).
  - Total responses counter & top course/goal metrics.
  - Search & filter functionality across all student submissions.
  - **One-Click CSV Export**: Downloads `bitfinder_responses.csv` formatted for pandas in Google Colab (`pd.read_csv('bitfinder_responses.csv')`).
- **Bitnox Office QR Code**: Instant printable SVG QR code on the thank-you screen for office scanning.

## 💻 Running Locally

Simply start a web server in the project directory:

```bash
# Using Python
python -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

## 🗄️ Supabase SQL Schema

To sync survey responses with Supabase Cloud, run this SQL query in your Supabase SQL Editor:

```sql
CREATE TABLE bitfinder_surveys (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  age_range TEXT,
  education_level TEXT,
  current_status TEXT,
  tech_experience TEXT,
  interest_areas TEXT,
  learning_style TEXT,
  main_goal TEXT,
  available_time TEXT,
  budget_range TEXT,
  career_path TEXT,
  course_picked TEXT,
  achievement_text TEXT,
  submitted_at TIMESTAMPTZ DEFAULT NOW()
);
```
